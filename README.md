# Indirizzo principale di FLOW

Questi file sono pubblicati nel repository `RiccardoVittori/riccardovittori.github.io` tramite GitHub Pages dalla radice del branch predefinito.

`https://riccardovittori.github.io/` reindirizza immediatamente a `https://riccardovittori.github.io/flow/`, anche senza JavaScript. Il link HTML resta disponibile come fallback. Il sito e la sua pipeline restano nel repository `RiccardoVittori/flow`; questa cartella ne conserva la configurazione di ingresso.

Per aggiornare la destinazione, modificare insieme meta refresh, canonical e link in `index.html`, quindi riportare i file nel repository del sito account. Nessun token o file `.env` deve essere pubblicato.
